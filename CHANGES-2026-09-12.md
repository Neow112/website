# Исправления SAPFIR — 12 сентября 2026

Обновлён архив сайта. Публикация на GitHub Pages не выполнялась.

## Выполнено

- Исправлено резервное копирование: служебный сценарий разрешён, результат проверяется, при отказе показывается ошибка. Копирование обычного текста остаётся ограниченным.
- Добавлены явные кнопки копирования и ссылки звонка для двух существующих номеров. WhatsApp и удержание номера сохранены.
- Ограничение контекстного меню применяется к медиа, а не ко всем ссылкам и странице. Это ограничение интерфейса, а не гарантия защиты изображений от скачивания.
- На первом экране добавлено действие «Узнать стоимость и свободную дату». Оформление и переход к видео сохранены.
- Казахская и уйгурская версии вынесены в /kk/ и /ug/. Переключение работает обычными ссылками без JS. Каждая страница содержит только свой видимый перевод, собственные title, description, canonical, социальные метаданные, WebPage и hreflang. sitemap содержит три URL.
- Удалена зависимость выбора языка от localStorage: язык определяется адресом страницы.
- H1 дополнен описанием коллектива и города для доступности и SEO, визуальный логотип сохранён.
- Добавлен переход к основному содержимому для клавиатурной навигации.
- Локализованы подписи управления портретами, фото галереи, названия видео и вступления.
- Удалён начальный src изображения в скрытом lightbox. До открытия фото не должно запрашиваться из этого элемента.
- Завершение интро и снятие inert привязаны к текущей CSS-анимации. Поздний JS не запускает таймер вступления заново. Сохранены «Пропустить», Escape, reduced motion и страховочное завершение.
- Удалено изменение margin-bottom главного экрана при прокрутке; анимация текста остаётся через transform.
- Добавлена простая 404-страница.
- CSS/JS получили новые имена с хешем. В CSS обновлены правила языковых ссылок и добавлены стили новых кнопок; полный рефакторинг всей таблицы стилей не выполнялся.
- Все исходные изображения, домен CNAME и файл подтверждения Яндекса сохранены.

## Проверка

- Синтаксис итогового JavaScript — node --check.
- Автоматическая проверка локальных src/href/srcset и якорей на трёх страницах.
- Проверка уникальности id, единственного H1, наличия canonical/hreflang, парсинга JSON-LD и соответствия страниц языкам.
- Изолированные тесты реальных функций JS: успех Clipboard API; отказ API с успешным резервным копированием; возврат false и исключение резервного метода; очистка служебного состояния; сохранение ограничения обычного текста.
- Изолированные тесты интро: JS после завершения анимации не блокирует страницу; завершение активной анимации снимает inert.

Браузерный предпросмотр локального сервера недоступен в этой среде. Поэтому реальная вёрстка на устройствах, буфер обмена мобильных браузеров, воспроизведение YouTube, работа приложения WhatsApp и показатели Lighthouse не подтверждены. Отдельные тесты логики не заменяют такие проверки.

## Что требует следующих действий

- Программы, длительность, география выезда, цены, отзывы и опыт: нужны реальные сведения от владельца; выдуманные данные не добавлены.
- Аналитика: нужны выбранная система и идентификатор счётчика; сторонние трекеры не подключены.
- Индексация: проверка /, /kk/, /ug/ и отправка sitemap в кабинетах владельца.
- HTTP-заголовки CSP/HSTS и прочие настройки сервера: требуют подходящего хостинга или прокси, архив HTML не может настроить их на GitHub Pages.
- Более глубокая оптимизация главного изображения, отдельная обложка соцсетей, контраст и мобильная вёрстка — после визуального просмотра и замеров. Alt галереи использует существующие подписи без выдуманного описания сцены.
- Новые короткие переводы кнопок желательно проверить носителем казахского/уйгурского языка.
