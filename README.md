# SAPFIR — sapfirshow.kz

Сайт собирается автоматически из данных: при каждом изменении в `main` GitHub Action запускает `tools/build.py` и публикует RU (`/`), KZ (`/kk/`) и UG (`/ug/`).

## Что где лежит

- `content/content.json` — всё, что меняется: участницы, галерея, видео, тексты разделов на трёх языках, телефоны, соцсети, сообщение для WhatsApp. Этот файл правит приложение-редактор.
- `src/ru.html`, `src/kk.html`, `src/ug.html` — шаблоны страниц (вёрстка и неизменяемые надписи). Места `{{t:…}}` и `{{@…}}` заполняет генератор.
- `src/strings.json` — служебные подписи для генерируемых блоков на каждом языке.
- `assets/`, `images/`, `404.html`, `CNAME`, `robots.txt`, `sitemap.xml`, `favicon.svg` — копируются на сайт как есть.
- `tools/build.py` — генератор (только стандартный Python 3.9+).

Готовые `index.html`, `kk/`, `ug/` в репозитории не хранятся — их создаёт сборка. Править вёрстку — в `src/*.html`, данные — в `content/content.json`.

## Локально

```
python tools/build.py          # собрать в _site/
python tools/build.py --check  # только проверить данные
```

Если в данных ошибка (номер не из 11 цифр, нет перевода, нет файла фото, чужая ссылка на видео), сборка останавливается с понятным сообщением, а на сайте остаётся прошлая рабочая версия.
