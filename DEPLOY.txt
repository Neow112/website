SAPFIR — FINAL OPTIMIZED PRODUCTION BUILD

Для GitHub Pages:
1. В корне репозитория замените index.html.
2. Загрузите ЦЕЛИКОМ папку assets/.
3. Загрузите ЦЕЛИКОМ папку images/. В ней теперь находятся JPG + WebP + AVIF и мобильные 900px-версии галереи.
4. Загрузите favicon.svg, robots.txt, sitemap.xml и .nojekyll в корень.
5. Старые fingerprint-файлы в assets/ можно удалить после загрузки новых:
   - site.6d51152e0d.css
   - site.869fc22bd2.js
6. .htaccess нужен только на Apache-хостинге. GitHub Pages его не использует; наличие файла не влияет на работу сайта.
7. После коммита дождитесь завершения GitHub Pages deployment, затем проверьте сайт в режиме инкогнито.

ВАЖНО:
- Не переименовывайте файлы AVIF/WebP и fingerprint CSS/JS: пути уже прописаны в index.html.
- Не удаляйте JPG из images/: они оставлены как fallback и используются для Open Graph / соцсетей.
- На современных браузерах галерея/портреты/интро выбирают AVIF, затем WebP, затем JPG.
- Для hero используется main.webp, чтобы сохранить существующую SVG-маску без изменения дизайна.

- карточки участниц;
- галерею и свайпы;
